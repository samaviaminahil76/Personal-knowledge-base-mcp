Unit 1: Introduction & Intelligent AgentsArtificial Intelligence (AI) is the study of agents that receive percepts from the environment and perform rational actions to maximize their chance of success.Environment TypesThe design of an agent depends heavily on the properties of its environment:Fully vs. Partially Observable: Does the agent’s sensors give access to the complete state of the environment at any given time? (e.g., Chess is fully observable; Poker is partially observable).Deterministic vs. Stochastic: Is the next state fully determined by the current state and action? (If uncertainty is involved, it is stochastic).Static vs. Dynamic: Does the environment change while the agent is deliberating? (e.g., Crossword puzzles are static; driving a car is dynamic).Discrete vs. Continuous: Are there a limited number of distinct states and actions?Agent ArchitecturesSimple Reflex Agent: Acts strictly on current percepts using condition-action rules ($IF \ text \ THEN \ action$). No memory of past states.Model-Based Agent: Maintains an internal state (a model of the world) to handle partial observability.Goal-Based Agent: Combines state information with explicit goals to plan sequences of actions.Utility-Based Agent: Uses a utility function to measure how desirable a particular state is, allowing trade-offs between competing goals.Unit 2: Problem Solving by SearchSearch algorithms systematically traverse a state space from an initial state to a goal state.State Space Graph  -->  Search Tree Expansion  -->  Goal State Evaluation
1. Uninformed (Blind) SearchThese strategies have no additional information about states beyond the problem definition.Breadth-First Search (BFS):Expands the shallowest node first using a FIFO queue.Completeness: Complete (if branching factor $b$ is finite).Time & Space Complexity: $\mathcal{O}(b^d)$, where $d$ is the depth of the shallowest solution.Depth-First Search (DFS):Expands the deepest node first using a LIFO stack.Space Complexity: $\mathcal{O}(bm)$, where $m$ is maximum depth (much lower memory footprint than BFS).Uniform Cost Search (UCS):Expands the node with the lowest path cost $g(n)$ using a priority queue (Dijkstra's Algorithm variant).2. Informed (Heuristic) SearchUses domain-specific knowledge via a heuristic function $h(n)$ (estimated cost from node $n$ to the goal).Greedy Best-First Search: Evaluates nodes using $f(n) = h(n)$. Fast, but not guaranteed to find the shortest path.A* Search: Evaluates nodes using:$$f(n) = g(n) + h(n)$$$g(n)$: Actual cost from start node to $n$.$h(n)$: Estimated cost from $n$ to goal.Admissibility Condition: $h(n)$ must never overestimate the actual cost to reach the goal ($h(n) \le h^*(n)$).Consistency (Monotonicity): For every node $n$ and successor $n'$ generated by action $a$:$$h(n) \le c(n, a, n') + h(n')$$3. Adversarial Search (Game Playing)Used in multi-agent competitive environments.Minimax Algorithm:MAX aims to maximize the utility score; MIN aims to minimize it.Recursively evaluates trees from leaf terminal nodes upward.Alpha-Beta Pruning:Prunes branches that cannot possibly influence the final decision.$\alpha$: The best value that MAX can guarantee at or above the current node.$\beta$: The best value that MIN can guarantee at or above the current node.Pruning occurs when $\alpha \ge \beta$.Unit 3: Knowledge Representation & LogicFormal logic allows agents to represent facts about the world and draw valid inferences.Propositional Logic (PL)Deals with simple declarative statements (propositions) that are either True or False.Operators: $\land$ (AND), $\lor$ (OR), $\neg$ (NOT), $\implies$ (Implication), $\iff$ (Biconditional).Limitation: Lack of expressiveness; cannot handle objects, properties, or relations efficiently.First-Order Logic (FOL)Introduces objects, relations, functions, and quantifiers to express complex knowledge.Quantifiers:Universal ($\forall$): "For all" — $\forall x \ \text{Student}(x) \implies \text{Studies}(x)$Existential ($\exists$): "There exists" — $\exists x \ \text{Student}(x) \land \text{Passed}(x)$Inference Rules:Modus Ponens: Given $\alpha \implies \beta$ and $\alpha$, infer $\beta$.Unification: Finding substitutions that make different logical expressions identical.Resolution: A sound and complete inference rule using Conjunctive Normal Form (CNF).Unit 4: Machine Learning & Probabilistic Reasoning1. Machine Learning ParadigmsParadigmObjectiveTypical AlgorithmsSupervised LearningMap inputs $X$ to labeled output $Y$Linear Regression, Decision Trees, KNN, SVMUnsupervised LearningFind hidden patterns/structures in unlabeled dataK-Means, Hierarchical Clustering, PCAReinforcement LearningLearn optimal policy $\pi$ via rewards and penaltiesQ-Learning, Deep Q-Networks (DQN)2. Decision Tree InductionSplits data based on feature value that maximizes Information Gain.Entropy (measure of impurity):$$H(S) = - \sum_{i=1}^{c} p_i \log_2(p_i)$$Information Gain:$$IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{\vert{}S_v\vert{}}{\vert{}S\vert{}} H(S_v)$$3. Handling UncertaintyReal-world environments require probabilistic reasoning.Bayes' Theorem:$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}$$Bayesian Networks: Directed Acyclic Graphs (DAGs) representing conditional dependencies among random variables.Unit 5: Neural Networks & Deep LearningArtificial Neural Network (ANN) ArchitectureAn ANN mimics biological neurons using layers of interconnected nodes.Input Layer (X1, X2)  -->  Hidden Layer (Weights + Biases + Activation)  -->  Output (Y)
The Single PerceptronComputes a weighted sum of inputs, adds a bias, and applies an activation function:$$z = \sum_{i=1}^{n} w_i x_i + b$$$$\hat{y} = g(z)$$Key Activation FunctionsSigmoid: $g(z) = \frac{1}{1 + e^{-z}}$ (Maps values to $[0, 1]$)ReLU (Rectified Linear Unit): $g(z) = \max(0, z)$ (Solves vanishing gradient problem in deep networks)Softmax: Used in multi-class classification output layers to convert raw logits to probabilities.Training via BackpropagationForward Pass: Calculate predictions ($\hat{y}$) and compute Loss $L(y, \hat{y})$ using functions like Mean Squared Error (MSE) or Cross-Entropy.Backward Pass: Compute partial derivatives of the Loss function with respect to weights ($\frac{\partial L}{\partial w}$) using the Chain Rule.Weight Update (Gradient Descent):$$w_{new} = w_{old} - \eta \frac{\partial L}{\partial w}$$(where $\eta$ is the learning rate).
